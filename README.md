# WG-Planer

Web-App für den WG-Alltag:

- **Putzplan** – Aufgaben rotieren automatisch reihum, mit Fälligkeit und „Weitergeben“
- **Einkaufsliste** – abhaken und direkt als Ausgabe in die Kasse übernehmen
- **Kasse** – geteilte Ausgaben, Salden pro Person und Vorschläge zum Ausgleichen
- **Pinnwand** – Zettel und Termine
- **WG** – Mitbewohner und Name der WG

Einfach `index.html` im Browser öffnen. Ohne Server werden die Daten im `localStorage` des Geräts gespeichert.
